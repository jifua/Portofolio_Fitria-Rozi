01

OnionBot AI Platform

PythonFastAPIONNX RuntimeOpenCVDocker

Sistem AI full-stack untuk deteksi penyakit daun bawang dari gambar yang diunggah, dengan skor kepercayaan dan rekomendasi penanganan berbasis knowledge base pertanian. Backend FastAPI menyajikan model deep learning dalam format ONNX untuk inferensi ringan. Dilengkapi mini-RAG chatbot (knowledge base lokal + pencarian Wikipedia), riwayat prediksi (SQLite), dashboard analitik, dan sistem autentikasi pengguna. Di-containerize dengan Docker dan di-deploy ke Hugging Face Spaces, termasuk debugging lintas platform (Windows→Linux) untuk isu case-sensitivity, dependency, dan Git LFS.

02

Tomato Leaf Disease Classification

TensorFlowMobileNetHailo AIRaspberry Pi 5

CNN berbasis MobileNet untuk klasifikasi 10 kelas penyakit daun tomat, mencapai 98% akurasi pada dataset 8.000+ gambar (Kaggle & Mendeley). Model dikonversi dari ONNX ke format Hailo HEF untuk deployment di edge device, lalu dijalankan real-time di Raspberry Pi 5 dengan kamera — mencapai 100% akurasi pada data lapangan. Proyek riset MBKM di Pusat Riset Fotonika, BRIN.
